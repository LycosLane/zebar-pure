# Zebar Pure (Widget Package)

Minimalist, high-performance React + TypeScript widget package for **Zebar Pure** (`lycoslane.zebar-pure`).

## Build Scripts

In this directory, you can run:

### `npm run build`
Builds the widget bundle into `minimal/dist/` using Vite.

### `npm run dev`
Runs Vite in watch mode to automatically rebuild on source changes.
